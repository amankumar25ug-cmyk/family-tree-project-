\# Family Tree Project in C



\## About the Project



This project is written in the C programming language. It stores information about seven family members and displays their family relationships.



The project uses structures, pointers, dynamic memory allocation, and functions.



\## Family Members



The program collects information about these seven people:



1\. Paternal Grandfather

2\. Paternal Grandmother

3\. Maternal Grandfather

4\. Maternal Grandmother

5\. Father

6\. Mother

7\. Myself



\## Features



\* Creates Person structures using dynamic memory allocation.

\* Takes the name and age of each family member as input.

\* Uses pointers to connect parents and children.

\* Displays the names, ages, and parent relationships.

\* Frees allocated memory using `free()`.



\## Technologies Used



\* C Programming Language

\* GCC Compiler

\* Git and GitHub



\## How to Compile



Open a terminal in the project folder and run:



```bash

gcc -Wall -Wextra -std=c11 family\_tree.c -o family\_tree

```



\## How to Run



On Windows, run:



```cmd

family\_tree.exe

```



On Linux, run:



```bash

./family\_tree

```

The program uses `malloc()` to allocate memory for each family member and `free()` to release the allocated memory.
